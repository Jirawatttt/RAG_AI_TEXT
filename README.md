# Smart Rights Viewer

ระบบตรวจสอบ **สิทธิประโยชน์ภาครัฐเบื้องต้น** จากข้อความภาษาไทยแบบอิสระแค่พิมพ์เล่าสถานการณ์ตัวเอง (อายุ สถานะงาน ประกันสังคม รายได้ สัญชาติ ฯลฯ) ระบบจะค้นหาหลักฐานจากคลังความรู้ด้วย **RAG** แล้วให้ **LLM** เป็นผู้ตัดสินว่าเข้าเกณฑ์สิทธิใดบ้าง

> ผลลัพธ์เป็นข้อมูลคัดกรองเบื้องต้นเท่านั้น ไม่ใช่การรับรองสิทธิหรือผลอนุมัติ หน่วยงานเจ้าของสิทธิเท่านั้นที่ตรวจสอบและยืนยันผลจริงได้
---
## จุดเด่น

- **พิมพ์ข้อความอิสระ** ไม่ต้องกรอกฟอร์มหลายขั้นตอน รองรับข้อความที่เขียนติดกันไม่เว้นวรรค
- **RAG + LLM** — ค้นหลักฐานที่เกี่ยวข้องก่อน แล้วให้ AI ตัดสิน
- **แบ่งผลชัดเจน 3 สถานะ**: อาจมีสิทธิ / อาจมีสิทธิแต่ต้องตรวจเพิ่ม / ยังไม่น่ามีสิทธิ พร้อมเหตุผลและแหล่งอ้างอิง
- **คำถามเพิ่มเติม**แนะนำคำถามที่ช่วยให้ผลแม่นขึ้น
- **กันข้อความนอกเรื่อง/พิมพ์ผิด** ก่อนส่งเข้า AI วิเคราะห์จริง
- **แดชบอร์ดสถิติ** สรุปสิทธิยอดนิยมและหมวดหมู่ที่ถูกค้นหาบ่อย
- **AI Input Assistant** แนะนำข้อมูลที่ควรเพิ่มระหว่างพิมพ์

## เทคโนโลยีที่ใช้
| ส่วน | เทคโนโลยี |
| --- | --- |
| Backend | Python, FastAPI, SQLAlchemy (async), PostgreSQL |
| AI | LLM Model OpenAI (`gpt-5.6-luna`) + Embeddings (`text-embedding-3-small` สำหรับ RAG) |
| Frontend | HTML, CSS, JavaScript (vanilla), Chart.js |

## ข้อจำกัด

ระบบครอบคลุมเฉพาะสิทธิที่มีอยู่ในคลังความรู้ ผลลัพธ์มาจากการตีความของ AI ไม่ใช่กฎตายตัว จึงอาจมีความคลาดเคลื่อนได้ **ควรตรวจสอบกับหน่วยงานเจ้าของสิทธิก่อนดำเนินการจริงเสมอ** — รายละเอียดเชิงเทคนิคและข้อจำกัดทั้งหมดอยู่ที่ [`Backend/README.md`](./Backend/README.md)
